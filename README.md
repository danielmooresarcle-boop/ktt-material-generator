# 快团团素材生成器

这是一个无需安装、无需构建的单文件静态网页。用户可以在浏览器中填写商品信息、上传本机商品图和已有二维码、切换海报版式、实时预览，并导出 `720 × 1280` 像素的 PNG 海报。

## 本地使用

1. 用 Chrome 或其他现代浏览器直接打开 `index.html`。
2. 填写商品文案、价格、卖点和发货信息。
3. 从本机选择商品主图与已有二维码。
4. 选择版式、主图比例和展示方式。
5. 检查右侧预览，然后点击“导出 PNG”。

图片仅在当前浏览器页面中读取和绘制。页面刷新或关闭后不会自动保存草稿。
